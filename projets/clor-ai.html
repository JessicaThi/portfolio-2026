Le contexte

Retoucher une photo avec l'IA

Clor AI est un éditeur photo : calques, pinceau, texte, recadrage, et des outils d'IA pour retoucher un portrait, changer une pose ou corriger les couleurs.

J'ai rejoint Infinique en janvier 2026. Une seule base de code sert pour le web, l'application ordinateur et l'application mobile. Mon rôle : construire les écrans à partir des maquettes Figma, puis développer des outils de retouche, surtout sur mobile.

Ce que j'ai fait

De l'interface aux outils de retouche

  • 01.2026Bases de l'interface : couleurs et polices dans Tailwind.css, icônes, composants communs (menus déroulants, fenêtres, notifications), pages de connexion et d'inscription.
  • 02.2026Outils de l'éditeur : barres d'outils, panneaux pinceau, texte et formes, sélecteur de couleur, panneaux déplaçables ; poignées pour redimensionner, aligner et faire pivoter les calques.
  • 03.2026Couleurs d'un portrait : panneau de correction des couleurs, avec curseurs et préréglages.
  • 04.2026Application mobile : accueil, bibliothèque, projets, corbeille, abonnement, stockage cloud, FAQ, inscription avec vérification par SMS, et la page d'édition.
  • 07.2026Outils de retouche sur mobile : yeux, sourcils, maquillage, coloration des cheveux, silhouette, corrections pour la nourriture, l'intérieur et les produits. Les réglages restent modifiables après coup.
  • 08.2026Pose : écran d'édition de la pose (squelette), préréglages de poses.
  • 09.2026Corrections : bugs remontés par les tests du client, traductions de l'interface (12 langues).

Ce que j'ai appris

Coder avec l'IA

Sur Clor AI, je développe avec Claude Code au quotidien. J'ai appris à m'en servir avec une méthode :

  • ContexteDonner les bonnes consignes : je mets à jour le fichier de consignes du projet pour l'IA (AGENTS.md), par exemple les couleurs du design system, pour que le code proposé suive nos conventions.
  • DécoupageUn problème à la fois : un bug ou une fonctionnalité par changement, avec un message clair et le numéro du bug signalé par le client.
  • VérificationTester avant de valider : tests automatisés sur les réglages de retouche, et un outil de recette construit avec l'équipe, qui montre le retour du client pour chaque bug et rejoue le scénario dans l'application.
  • RelectureGarder la main : je relis chaque changement et je le teste moi-même dans l'application avant de l'envoyer.

C'est ce qui m'a permis, par exemple, d'adapter les outils de retouche de la version ordinateur à l'application mobile, puis de corriger les bugs remontés par le client.
