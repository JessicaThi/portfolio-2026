# Portfolio — Jessica Thielemans

Développeuse front-end à Séoul. Site : [jessica-thielemans.com](https://jessica-thielemans.com)

Site statique en HTML, CSS et JavaScript, sans outil de build. Ouvrir `index.html` dans le navigateur.

- `index.html` : l'accueil (parcours, projets, contact), en français, anglais et coréen
- `projets/` : une page par projet
- `portfolio-2020/` : l'ancienne version du portfolio (2020)
